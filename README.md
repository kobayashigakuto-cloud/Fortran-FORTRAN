# Fortran-FORTRAN

研究で使用する数値解析プログラムを作成しています。

当初FORTRANで作成したプログラムについて、保守性や可読性の向上を目的として、Modern Fortranへの移行を進めています。

また、解析実行の自動化を目的として、Shell Scriptを用いた計算補助プログラムも作成しています。

随時、既存プログラムも掲載、改訂する予定です。

## 内容

### 数値解析プログラム
- 各種解析用プログラム
- FORTRANコード
- Modern Fortranへ移行したコード

### 蒸着計算プログラム
- 蒸着プロセス計算用プログラム
- 計算実行用Shell Script
- ジョブ管理・自動実行スクリプト

## 使用技術
- FORTRAN
- Modern Fortran
- Shell Script
- Linux

## 目的
- 研究で使用する解析プログラムの開発
- レガシーコードのModern Fortran化
- 計算業務の自動化
