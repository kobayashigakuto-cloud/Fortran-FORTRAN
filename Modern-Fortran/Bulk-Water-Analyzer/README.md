# Water System Analyzer

分子動力学計算結果から水素結合構造を解析するプログラムです。

## 主な機能

- 水素結合判定
- Dangling OH判定
- d5解析
- 配位数分布解析
- HOH角評価
- 周期境界条件(PBC)対応

## 使用技術

- Modern Fortran
- Module
- Subroutine
- Dynamic Allocation

## 入力

- file07.dat
- file09p.dat
- parardf.dat

## 出力

- Parameter_Hbond.dat
- Parameter_dangling.dat
- d5.dat
- hb_distribution.dat
