# H2O Bulk Legacy Analyzers

水バルク系の分子シミュレーション結果を解析するために作成した、
旧版Fortranプログラム群です。

当初は解析項目ごとに独立したプログラムとして作成していました。
現在は処理の重複を整理し、Modern Fortran版の
`Bulk-Water-Analyzer`へ統合しています。

## プログラム一覧

### `d5_distribution.f`

各酸素原子について、周期境界条件を考慮して近接酸素を探索し、
時間平均した第5近接酸素間距離の累積分布を計算します。

出力：

- `d5.dat`

### `normalized_d5_ratio.f`

第1～第3近接酸素間距離の平均を基準として、
第5近接酸素間距離を規格化します。

出力：

- `d5_ratio_bulk.dat`

### `hb_distribution.f`

距離条件と角度条件から水素結合を判定し、
酸素原子ごとの水素結合数分布を計算します。

出力：

- `hb_distribution.dat`

### `dangling_oh.f`

水素原子に近接する酸素原子を探索し、
水素結合状態、平均位置、OH結合の配向角を解析します。

出力：

- `danglingOH.dat`

## 共通の入力ファイル

- `file07.dat`
  - 原子数、原子種、原子番号範囲
- `file09p.dat`
  - セルサイズおよび各計算ステップの原子座標
- `parardf.dat`
  - 解析開始・終了ステップなどの条件

## Legacy版の特徴

- 解析項目ごとにプログラムが独立
- 固定長配列を使用
- 入力、解析、出力処理が各プログラム内で重複
- 一部の原子番号や判定条件を直接指定
- 周期境界条件を考慮した距離計算を使用

## Modern Fortran版への統合

これらのプログラムは、Modern Fortran版の
`Bulk-Water-Analyzer`へ統合しました。

主な変更点：

- 距離・角度計算の共通化
- Moduleによる機能整理
- allocatable配列への変更
- 共通入力処理の統合
- 水素結合、Dangling OH、d5解析の一括実行
- 可読性、保守性、拡張性を考慮した再設計
