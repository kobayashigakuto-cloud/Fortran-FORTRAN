# Active Programs

水バルク系の解析で現在も使用している、F77形式のプログラム群です。

解析目的ごとに独立しており、必要に応じて個別に実行します。

## プログラム一覧

### `void_fraction.f`

計算セルを格子状に分割し、酸素・水素原子からの距離を基に、
z方向ごとの空隙率を計算します。

出力：

- `spaceH2O.dat`

### `water_orientation.f`

各酸素原子に近い2つの水素原子を探索し、
水分子の配向角分布を計算します。

出力：

- `modified.dat`

### `statistics_converter.f`

温度ごとの統計データを読み込み、
解析項目別のファイルへ平均値と95%区間用の値を整理して出力します。

出力：

- `01_OH_dist.dat`
- `02_OH_angle.dat`
- `03_O_H_dist.dat`
- `04_H_angle.dat`
- `05_HOH_angle.dat`

### `normalized_d5.f`

各酸素原子について第1～第5近接酸素を探索します。

第1～第3近接距離の平均で第5近接距離を規格化し、
規格化距離の累積割合を計算します。

出力：

- `d5_ratio_bulk.dat`

## 共通入力ファイル

- `file07.dat`：原子数、原子種、原子番号範囲
- `file09p.dat`：セルサイズおよび原子座標
- `parardf.dat`：解析ステップなどの条件

## 位置付け

これらは現在も個別の解析に使用しているため、
統合済みコードとは分けて保存しています。
