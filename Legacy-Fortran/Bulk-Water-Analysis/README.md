# H2O Bulk Legacy Analyzer

水バルク系のシミュレーション結果から、酸素原子周辺の構造を解析する旧版Fortranプログラムです。

現在は、このプログラムを基にModern Fortran版への書き換えと機能統合を進めています。

## 解析内容

各酸素原子について、周期境界条件を考慮して近接する酸素原子を探索します。

主な処理は以下のとおりです。

- 酸素原子間距離の計算
- 周期境界条件の適用
- 近接する5個の酸素原子の探索
- 第1～第3近接距離の平均による規格化
- 規格化した第5近接距離の分布計算

## 入力ファイル

- `file07.dat`
  - 原子数
  - 原子種
  - 原子番号の範囲
- `file09p.dat`
  - セルサイズ
  - 各ステップの原子座標
- `parardf.dat`
  - 解析開始ステップ
  - 解析終了ステップ
  - 計算条件

## 出力ファイル

- `d5_ratio_bulk.dat`
  - 規格化した第5近接距離の累積割合
